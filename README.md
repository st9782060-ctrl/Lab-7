2. **Задача 2.7 (`task_2` — Lab 2.3.2):** обчислення наближеного значення числа $\pi$ за рядом Лейбніца для заданої кількості ітерацій із використанням циклу `for`.
3. **Задача 2.10 (`task_3` — Lab 2.3.5):** побудова псевдографічного контуру квадрата заданого розміру $n$ із перевіркою допустимих меж та використанням вкладених циклів `for`.
